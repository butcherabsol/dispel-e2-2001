# Dispel at E2 — 2001 website

A local restoration of the archived Dispel website, including Korean and English text and the saved system information page.

To preview the site, run this command from the repository directory:

```sh
python3 -m http.server 8000
```

Then open [the homepage](http://localhost:8000/homepage/Home%20page%20of%20dispel.htm). Use the language button below the menu to switch between Korean and English.

Some pages and downloads were not present in the saved files; their links point to the Internet Archive. A few original image files were saved as error pages and still need restoration.
